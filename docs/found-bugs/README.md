# Found bugs

Catatan bug yang ditemukan di luar daftar backlog: apa gejalanya, apa akar
masalahnya, bagaimana diperbaiki, dan apa yang belum.

Nama file: `<area>-<topik>-<ddmmyyyy>.md` (contoh:
`employee-portal-payroll-26112026.md`).

Isi minimal:

1. **Gejala** — apa yang terlihat pengguna.
2. **Akar masalah** — file/fungsi penyebabnya.
3. **Perbaikan** — perubahan yang dilakukan.
4. **Bukti** — test/perintah/screenshot yang membuktikan.
5. **Belum diperbaiki** — bagian terpisah, jangan dicampur dengan yang sudah
   beres.

Statusnya dilacak di `docs/plan/backlog.md` (item ERP) dan dirangkum di
`docs/plan/progress.md`; dokumen di folder ini menyimpan detail teknisnya.
