# UAT modul programmer kedua (Oki)

Kembali ke [UAT modul](../README.md). Checklist uji terima untuk modul yang
dikerjakan Oki, dengan format yang sama seperti modul programmer B: setiap
langkah berisi menu, isian, tombol, hasil yang harus terlihat, uji salah, lalu
`[ ] Sesuai` dan tabel kecil ketidaksesuaian di bawahnya.

Disusun 2026-11-26 dari pembacaan kode (belum diuji di aplikasi). Temuan di
sini adalah **pertanyaan untuk Oki**, bukan perbaikan yang langsung
dikerjakan programmer B.

| Modul | File | Isi |
|---|---|---|
| M01 Dasbor | [m01-dasbor.md](m01-dasbor.md) | Dasbor per role |
| M06 Aset & Peralatan | [m06-aset-peralatan.md](m06-aset-peralatan.md) | Aset, peralatan, peminjaman, perawatan |
| M09 Keuangan (transaksi) | [m09-keuangan-transaksi.md](m09-keuangan-transaksi.md) | Akun, jurnal, piutang/utang, kas/bank, aset tetap, anggaran, tutup periode |
| M09 Keuangan (laporan) | [m09-keuangan-laporan.md](m09-keuangan-laporan.md) | Neraca saldo, laba rugi, neraca, arus kas, laporan manajemen |
| M10 Pajak | [m10-pajak.md](m10-pajak.md) | PPN, PPh 21, pemotongan, Coretax |
| M11 Bonus & Investor | [m11-bonus-investor.md](m11-bonus-investor.md) | Investor, bagi hasil, portal investor |
| M12 Laporan & Hak Akses | [m12-laporan-hak-akses.md](m12-laporan-hak-akses.md) | Login, pengguna, undangan, role, audit, profil perusahaan, nomor kode |
| Portal karyawan | [portal-karyawan.md](portal-karyawan.md) | Absensi (termasuk lokasi proyek), cuti, dokumen, slip gaji |

**Urutan yang disarankan:** M12 (akun dan role) → M01 → M09 → M10 → M06 →
M11 → portal karyawan. Keuangan memakai data penjualan/pembelian dari modul
programmer B, jadi jalankan setelah M02 dan M05 bila ingin angkanya cocok.
