## Catatan

- **Gate 2 (keputusan rancangan, disetujui pengguna):**
  - Proyek disimpan sebagai `reference_type = 'project'`, `reference_id = id proyek` di `inventory.movements` (tanpa kolom baru); proyek dicek lewat `ProjectLookupService.getProject` (harus `active`).
  - Status seri baru `issued` (keluar ke proyek/pemakaian sendiri; bisa kembali ke `in_stock` atau `lost`) → perubahan CHECK `item_serials` (docs.dbml + migrasi).
  - Biaya bahan proyek tampil di halaman proyek: bahan dari surat jalan + mutasi manual ke proyek (keluar positif, terima kembali negatif).
  - Belum ada jurnal GL untuk pengeluaran bahan; catatan untuk Oki.

- **Data uji di DB dev:** mutasi `MV-202611-000003`…`000006`; seri `SN-UAT-B29-01` berstatus `issued`.
