### 3. `PATCH /admin/users/:userId/roles`
**Akun:** Pemilik - Aqim
**Menu:** HTTP langsung `PATCH /admin/users/{userId}/roles`
**Isi dengan:** `{ "organizationId": "<org aktif>", "roles": ["sales","finance"] }`
**Klik:** Kirim
**Harus terlihat:** HTTP 200 `{ id, role: "sales,finance" }`; baris
`auth.members.role` berubah; log audit berisi `member.roleChanged`.

**Uji salah:**
- roles kosong `[]` → 400 validasi.
- role di atas tingkat pemanggil (mis. `admin` oleh akun `sales`) → 403
  "Peran tidak dapat diberikan: …".
- mencabut `owner` dari pemilik terakhir → 409 "Tidak dapat menghapus atau
  menurunkan pemilik terakhir".
- pengguna tanpa keanggotaan → 404 "Anggota tidak ditemukan".
